## 核心研究问题

在研究过程中，请始终围绕以下问题寻找答案：

1. **入口**：用户请求从哪里进入 `AgentSession`？
2. **调度**：`AgentSession` 如何驱动 LLM 和 Tool 循环？
3. **工具**：Tool 是如何被定义、注册和执行的？
4. **扩展**：Extension 机制如何实现功能的解耦与增强？
5. **状态**：Session 如何管理对话历史、分支和压缩？
