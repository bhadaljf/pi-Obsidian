## 五、第二周方向建议

转向项目实践，完成一个改造证明理解。

**方向 A：多 API/多模型路由**  
用户 → Pi Agent → Router → 简单任务/Model A / Coding/Model B / 长上下文/Model C

**方向 B：Session/Memory 改造**  
普通 Session → 增加长期记忆层 → 根据历史检索 Context → Agent

**方向 C：Agent Tool 改造**  
增加自定义 Tool，让 Agent 完成原本不能做的任务。

优先 A 或 B。
